## sloctl config delete-context

Delete chosen context(s)

### Synopsis

Delete one or more of the contexts from the configuration file.
Each argument is treated as a context name, when no arguments are provided a multi-selection prompt is displayed.

```

# Display interactive selection of context to delete (multiple choice).

# Delete "context-1" and "context-2" from your configuration file.
sloctl config delete-context context-1 context-2
```
